## 🚀 Overview
**Smartmarks** is a next-generation bookmark manager that goes beyond simple folders. By analyzing the content of saved URLs in real-time using Gemini 2.0, it automatically generates descriptive tags, summaries, and hierarchical categories. Its semantic search capability allows you to find "that article about neuralese I read last month" even if you don't remember the title.

## ✨ Key Features
- **Auto-Categorization**: Intelligent grouping of links based on semantic content.
- **Semantic Search**: Natural language query interface to find bookmarks by concept.
- **Content Summarization**: Instant snapshots of bookmarked pages for quick reference.
- **Browser Integration**: Ready for seamless injection into modern browsing workflows.

## 🛠️ Tech Stack
- **Frontend**: Vite + React + TypeScript
- **Styling**: Tailwind CSS
- **AI Engine**: Google Gemini API
- **Database**: LocalStorage / IndexedDB (Cloud sync ready)

## 🎮 Getting Started

### Installation
1.  **Clone & Install**:
    ```bash
    npm install
    ```
2.  **Environment**:
    Create `.env.local` and add `GEMINI_API_KEY=your_key_here`.
3.  **Run**:
    ```bash
    npm run dev
    ```
